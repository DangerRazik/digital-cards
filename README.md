# Digital Cards

Веб-приложение для создания и публикации электронных визиток.

В личном кабинете доступны регистрация и вход, создание и редактирование визиток, загрузка фото и обложки, предпросмотр, публикация и снятие с публикации. Посетители могут посмотреть опубликованную визитку и сохранить контакт в формате vCard. QR-код содержит постоянную ссылку на визитку.

## Структура

- `admin-web/` — личный кабинет на Angular и TypeScript.
- `public-web/` — отдельное Angular-приложение для просмотра визиток.
- `backend/` — API на NestJS и база PostgreSQL.
- `scripts/` — инструменты локальной разработки.
- `deploy/` — инструкции и конфигурации для сервера.

Редактирование доступно только владельцу после входа. Публичный API отдаёт только опубликованные данные. Сохранение черновика не меняет опубликованную версию до повторной публикации.

## Локальный запуск на Windows

Нужны Windows x64, Node.js 24 и доступ в интернет для первоначальной подготовки.

Из корня проекта один раз выполните:

```powershell
.\setup-local.ps1
```

Скрипт установит зависимости и подготовит локальный PostgreSQL 17.

Для запуска:

```powershell
.\start-local.ps1
```

- Личный кабинет: http://127.0.0.1:4201
- Публичные визитки: http://127.0.0.1:4200/{slug} — точная ссылка доступна в кабинете после создания визитки.
- Backend: http://127.0.0.1:3000/api

Для остановки базы выполните ` .\stop-db.ps1 `.

Локальная база и её настройки хранятся в `.local/`, загруженные изображения — в `backend/storage/`. Эти каталоги и рабочий `.env` исключены из Git.

## Развёртывание

Инструкция для Ubuntu, Node.js, PostgreSQL и Nginx: [deploy/INSTALL.txt](deploy/INSTALL.txt).
Настройки доменов и подключения к базе задаются для конкретного сервера. Скрипт первоначальной установки рассчитан на новую базу; для существующей базы настройку нужно адаптировать.
