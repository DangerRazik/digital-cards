# Стиль проекта

- Читаемость важнее краткости: код должен быть понятен начинающему Angular/TypeScript-разработчику.
- Одна независимая операция или свойство на строку. Разделяйте логические группы пустыми строками.
- Предпочитайте явные условия с ранним return вложенным ternary и сложным функциональным цепочкам.
- Используйте понятные имена и небольшие функции; не добавляйте классы и архитектурные слои ради размера файла.
- Сохраняйте inject(), signals, computed() и toSignal() там, где они полезны. RxJS оформляйте по этапам.
- Комментарии объясняют причины, а не пересказывают строки кода.
- При рефакторинге сохраняйте поведение, API, внешний вид, проверки безопасности и зависимости.
- Сохраняйте whitelist публичных полей, фильтрацию выключенных значений на сервере и проверки ссылок/изображений.
- Перед изменениями перечисляйте затрагиваемые файлы и назначение правок; работайте проверяемыми этапами.
- PowerShell-скрипты сохраняйте в UTF-8 с BOM для совместимости с Windows PowerShell 5.1.
- Не редактируйте зависимости и сгенерированные файлы ради форматирования.

- Не запускайте сборку и приложение самостоятельно. Команды build, start, ng serve выполняет пользователь, если явно не попросил иначе.
