Digital Cards

Нужны Ubuntu, Node.js 24, npm, Nginx, sudo и существующая пустая razildb.
Подготовка БД рассчитана на PostgreSQL 17 на этом же Linux-сервере и
администрирование через sudo -u postgres. Если это не так — нужен администратор БД.
Согласовать свободные порты 8081/8082; backend использует 127.0.0.1:3000.
HTTP — только внутренняя сеть, тестовые данные и пароли.
Команды ниже выполнять из корня скачанного проекта; при ошибке остановиться.

1. Собрать приложения обычным пользователем:
for project in backend admin-web public-web; do
  (cd "$project" && npm ci && npm run build) || break
done
Продолжать только если успешно собраны все три приложения.

2. Разместить файлы (первый раз):
sudo useradd --system --user-group --home-dir /var/lib/digital-cards --shell /usr/sbin/nologin digital-cards
sudo install -d -m 755 /opt/digital-cards
sudo cp -a backend admin-web public-web deploy /opt/digital-cards/
sudo chown -R root:root /opt/digital-cards
sudo chmod -R a+rX /opt/digital-cards
sudo install -d -o digital-cards -g digital-cards -m 700 /var/lib/digital-cards/images

3. Подготовить пустую БД и настройки ОДИН РАЗ:
sudo /usr/bin/node /opt/digital-cards/deploy/init-database.cjs http://10.3.237.134:8081 http://10.3.237.134:8082 razildb --internal-http

Если БД уже подготовлена — этот шаг пропустить. В существующем
/etc/digital-cards/backend.env проверить строки ниже, сохранив пароли и остальные настройки:
NODE_ENV=production
INTERNAL_HTTP=true
ADMIN_ORIGIN=http://10.3.237.134:8081
PUBLIC_CARD_ORIGIN=http://10.3.237.134:8082
HOST=127.0.0.1
PORT=3000
TRUST_LOCAL_PROXY=true

4. Запустить backend и настроить работающий Nginx:
Проверить command -v node. Если это не /usr/bin/node, исправить ExecStart в файле службы.
sudo install -m 644 deploy/digital-cards.service /etc/systemd/system/digital-cards.service
sudo systemctl daemon-reload
sudo systemctl enable --now digital-cards
sudo install -m 644 deploy/nginx.conf /etc/nginx/sites-available/digital-cards

Следующая команда нужна только если такой ссылки ещё нет:
sudo ln -s /etc/nginx/sites-available/digital-cards /etc/nginx/sites-enabled/digital-cards

sudo nginx -t
Только после успешной проверки:
sudo systemctl reload nginx

5. Проверить:
Кабинет: http://10.3.237.134:8081
Визитки: http://10.3.237.134:8082/{slug}
sudo systemctl status digital-cards
sudo journalctl -u digital-cards -n 50 --no-pager
Проверить вход, создание, фото, публикацию и открытие визитки с компьютера тестера.

При смене IP/портов поменять nginx.conf и оба адреса в backend.env.
Доступ к 8081/8082 разрешить только внутренним тестерам; allow в Nginx согласовать с администратором.
После изменения backend или backend.env: sudo systemctl restart digital-cards.
Код: /opt/digital-cards. Фото: /var/lib/digital-cards/images. Пароли: /etc/digital-cards/backend.env.
